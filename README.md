# 보령머드축제 안내 데모

[공개 시연 페이지](https://nenae16-creator.github.io/boryeong-festival-pages/)

제29회 보령머드축제(2026.7.24~8.9)의 공개 자료로 만든 비공식 시연용 앱입니다. 행사는 종료했으며 공식 서비스가 아닙니다.

프로그램 검색, 날짜별 관심 일정 저장, 가족·야간 관람계획, ICS 캘린더 내보내기, 출처가 있는 장소 지도, 주차·교통·이용 안내를 제공합니다. 실시간 혼잡도·주차 잔여·셔틀 도착·예매 기능은 없습니다.

공식 원문과 확인일: [data/sources.md](data/sources.md). 시각·장소가 미확인인 항목은 추정하지 않습니다. 관심 일정은 이 브라우저의 보령 전용 localStorage에만 저장하며 로그인·기기 간 동기화는 제공하지 않습니다.

디자인 v3: 자체 제작 바다 모티브 벡터, 10개 아이콘 메뉴, 가족·야간 관람 카드, 반응형 내부 화면. 파도 마크와 일러스트는 공식 로고·실제 행사 사진·배치도가 아닙니다.

정적 앱입니다. `index.html`을 직접 열거나 로컬 정적 서버에서 실행할 수 있습니다. JS 원천을 수정하면 `js/app.bundle.js`도 재생성해야 합니다. HTTPS/localhost에서 PWA 안내를 캐시합니다. 지도 타일·웹 글꼴·외부 공식 안내에는 인터넷이 필요합니다.

지도 Leaflet(BSD-2)·OpenStreetMap(ODbL), 글꼴 Pretendard·SUITE·Noto Serif KR(SIL OFL). 각 외부 자원의 원래 라이선스가 적용됩니다.
