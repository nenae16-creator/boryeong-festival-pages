# 보령머드축제 안내 데모

[공개 시연 페이지](https://nenae16-creator.github.io/boryeong-festival-pages/) · 이전 디자인 v3: [/v3/](https://nenae16-creator.github.io/boryeong-festival-pages/v3/)

제29회 보령머드축제(2026.7.24~8.9)의 공개 자료로 만든 **비공식 시연용 앱**입니다. 행사는 종료했으며 공식 서비스가 아닙니다.

새 축제 엔진(festival-engine, React·MapLibre)으로 만든 빌드 결과물입니다. 축제 내용은 `festival.json` 한 파일에서 나옵니다. 사진 홈 화면, 바로가기 10칸, 추천 코스 3종(날짜별 공식 일정), 날짜별 프로그램, 내 일정 저장·캘린더(ICS) 내보내기, OSM 지도, 주차·셔틀·요금·재단 행사·FAQ·분실물 안내를 제공합니다. 실시간 혼잡도·주차 잔여·셔틀 도착·예매 기능은 없습니다.

- 공식 자료 확인일 2026-10-13 (보령축제관광재단 누리집). 시각·장소가 미확인인 항목은 추정하지 않고 "확인 필요"로 표시합니다.
